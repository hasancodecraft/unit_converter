# Unit Converter App — Ostad Module 30

A simple Flutter app using the provider package. No API key, Firebase, internet, location access, or database is required.

## Features

- Length: Meter ↔ Kilometer
- Weight: Gram ↔ Kilogram
- Temperature: Celsius ↔ Fahrenheit
- Numeric input, including decimals and negative values
- Two dropdowns and a swap button
- The result updates immediately when the input or selected units change
- A blue-and-white screen inspired by the assignment reference image
